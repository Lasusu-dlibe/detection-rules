# Raw-log tuning notes

Source: `stratus-coverage/dataset/by_attack`.

## Changed rules

| Rule | Raw detonation evidence | Change |
|---|---|---|
| EC2 password data | 30 `GetPasswordData` calls returned `Client.UnauthorizedOperation` under one assumed role. | Threshold of 10 denied calls per actor. |
| EC2 user data | `DescribeInstanceAttribute` requested `attribute=userData` and returned `Client.UnauthorizedOperation`. | Require that error code. |
| EC2 GPU launch | `RunInstances` requested `instanceType=p2.xlarge` and returned `Client.UnauthorizedOperation`. | Require GPU family and failure together; removed the broad `OR` condition. |
| S3 lifecycle | `PutBucketLifecycle` had `Expiration.Days=1`. | Detect one-day expiration instead of matching the Stratus-specific `ctlr` bucket name. The rule no longer claims it can identify a CloudTrail bucket without external bucket inventory. |
| EC2 discovery | One EC2 instance-role session made denied calls to `ListBuckets`, `GetAccountSummary`, `ListRoles`, `ListUsers`, and `GetAccountAuthorizationDetails`. | Threshold of three discovery calls per instance-profile session. |
| SSM SendCommand | One successful request listed three target instance IDs. | Threshold rule uses cardinality of target instance IDs, with a threshold of two. |
| SSH ingress | The available dataset has no detonation `AuthorizeSecurityGroupIngress` event. | Replaced raw-string matching with the nested CloudTrail fields used by Elastic's AWS rule and reduced severity to High. Must be replay-tested after collecting the missing detonation event. |

## Not changed

* Lambda overwrite: raw data contains a successful `UpdateFunctionCode20150331v2`; the existing rule is aligned with that core event.
* SES enumeration: `dataset/by_attack` has no JSONL file for this technique. The query retains its four documented SES APIs and needs a raw-log run before further tuning.

## Validation still required in Kibana

The repository CLI validated the TOML schema. This does not prove a query matches the fields after Elastic Agent ingestion.

1. Import the tuned rules into a test Kibana space.
2. Replay or re-run each mapped Stratus attack.
3. Confirm the alert source event ID, not just an auxiliary warm-up alert.
4. For SSM, confirm `aws.cloudtrail.flattened.request_parameters.instanceIds` is a multi-value field usable by threshold cardinality.
5. Run matching benign workflows before accepting a production threshold or severity.
